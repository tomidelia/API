# Fotos de demo

Imágenes de relleno para cargar un catálogo de prueba, generadas con la paleta de
Mesa Llena. Sirven para dos cosas:

- Tener algo que subir desde el panel de la tienda (`/admin/productos/nuevo`) o
  desde Insomnia, sin salir a buscar archivos.
- Que el catálogo se vea completo cuando hay que mostrarlo.

**No son las tapas reales de los juegos.** Son placeholders con el nombre escrito
encima. Cuando tengamos las fotos de verdad, se reemplazan desde
`/admin/productos/:id/editar`: al subir fotos nuevas se pisan las anteriores.

`foto-producto.png` es el archivo chiquito que usa la colección de Insomnia en los
requests de alta de producto.
